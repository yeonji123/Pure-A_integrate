## 프로젝트 소개
IoT 기술을 활용한 공유 우산 및 폐우산 순환 시스템을 통해 무분별한 폐기물 처리로 인한 환경 오염 문제를 해결합니다. 이를 위해 효율적인 분리배출과 무상 우산 대여 서비스를 도입하고 어플리케이션을 활용하여 사용자의 편의성을 높이며 데이터 구축 및 활용 방안을 제시합니다. 기부받은 폐우산을 재활용하여 유지보수 한계를 극복하며, 환경 오염을 해결하고 올바른 분리배출을 돕습니다.
사용자에게 무료로 우산을 대여/반납할 수 있으며, 폐우산을 분리배출 해야 하는 번거로움을 해소해 주는 애플리케이션과 아두이노 기반 직접 작동하는 장치를 개발하였습니다.
안드로이드와 iso 연동이 가능한 React native를 사용하여 컴포넌트를 구현하고 애플리케이션을 제작하였습니다.
